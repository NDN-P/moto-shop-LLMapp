# Project proposal

I propose to extend an existing motorcycle parts management application with a read-only natural-language catalog assistant for shop staff. The existing React interface and SQLite workflows will remain the basis of the application. The assistant will use an entirely invented, explicitly marked sample catalog containing product names, categories, prices, stock quantities and minimum stock thresholds; real business records will stay outside the model workflow. Python will call the class proxy with the OpenAI client and the required `gemma-4-E4B-it` model. Native function calls will expose only validated product search, product details, low-stock lookup and inventory totals. Answers will include checked product IDs and a visible lookup trace, with bounded execution and a safe fallback when validation fails. I will compare the original name/SKU substring search with bilingual category, brand and size normalization on 30 hand-labeled synthetic questions, split into 10 development and 20 evaluation cases. Success will be assessed through reproducible retrieval measurements, observed live behavior, and honest reporting of failures and fitment limitations.
