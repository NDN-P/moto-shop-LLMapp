# Project proposal

I propose to extend an existing motorcycle parts management application with a read-only natural-language catalog assistant for shop staff, retaining the React interface, SQLite workflows and local login. Sample mode will use an explicitly marked invented catalog for reproducible evaluation and recording. Optional shop mode will read the configured inventory database without writes and send the question plus selected product IDs, names, SKUs, categories, prices, stock quantities and minimum stock thresholds, or computed inventory totals, to the approved course proxy at `https://llm.nat-d.uk/v1`. Descriptions, supplier details, photos and stock history will be excluded. Python will use the OpenAI client and required `gemma-4-E4B-it` model. Native function calls will expose validated search, product lookup, low-stock lookup and inventory totals. Answers will include checked source IDs and a visible trace, with bounded execution and a fallback when validation fails. I will compare the original name/SKU substring search, BM25, and bilingual category, brand and size normalization on 30 hand-labeled synthetic questions, split into 10 development and 20 evaluation cases. Those measurements and retained live sample observations will describe synthetic data only; real-inventory performance will require separate validation. Success will be assessed through reproducible measurements and honest reporting of failures and fitment limitations.
